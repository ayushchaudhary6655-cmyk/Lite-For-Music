# Lite For Music

Artist website with music, videos, profile links, and Too Far Gone artwork.

## Publish free on GitHub Pages

1. Upload this directory to a public GitHub repository. Keep `index.html` and `assets/` at the repository root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main**, choose **/ (root)**, and save.
5. Open the website address shown by GitHub Pages when deployment finishes.

A repository named `<username>.github.io` uses `https://<username>.github.io/`. Other repositories use `https://<username>.github.io/<repository>/`.

No build, dependencies, API keys, or server are required. Assets and fonts are included locally. Music previews use Spotify embeds, and social buttons open their respective platforms.

## Edit

Edit `index.html` for layout, styles, and interactions. Add image and font files under `assets/`. Commit changes to the publishing branch to update the website.
